## 📄 Descripción

Este frontend es parte del sistema de gestión de citas médicas para la clínica ECI Salud Vital. Permite a los usuarios visualizar especialidades médicas, agendar citas y revisar su historial, todo en una interfaz amigable y responsiva.

## 🚀 Instrucciones para Ejecutar

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/eci-salud-vital-frontend.git
cd eci-salud-vital-frontend

│ ├── AppoimentForm.jsx
│ ├── AppoimentHistory.jsx
│ ├── Home.jsx
│ └── SpecialityDetail.jsx
├── pages/
│ ├── Home.jsx
│ ├── Detalle.jsx
│ ├── Cita.jsx
│ └── Historial.jsx
├── services/
│ └── api.js
├── App.jsx
└── main.jsx

```
2. Instala las dependencias:

npm install

3. Ejecuta el servidor de desarrollo:
npm run dev
